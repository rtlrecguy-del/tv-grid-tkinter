Checkbox1.sh is a script that allows you to select from a playlist 2,4,6 or 8 urls and creates a script. <br>
That script can be run to play a grid in that combination.  It can run on standard linux or termux depending on the power of <br>
the computer.    
<br>
<br>
To mute and unmute each window:
   Right quadrant use directional or arrow keys on remote, keyboard controller.   Up/Down/Left/Right
   Second quadrant us same but use double clicks.
   To mute all windows click right three times.
   To exit click left three times
To exit checkbox1.sh script press key 1.


Some of the requirements are python-tkinter, python-requests and python-pip.
