selector1.sh allows you to choose by groups then by channels individually to create a new playlist file in the playlists folder that you can select for the grid when you run startgrid.sh.

The packages that are at least needed may have different names depending on operating system you are using but are:
libmpv-dev, mpv, python3-tkinter, python3-pip, xorg, dialog, pulseaudio

Commands to also run are pip install requests python-mpv and pip install -U yt-dlp.

I use tinywm, rofi and dmenu for my setup.   I would avoid tiling window managers when using it.
